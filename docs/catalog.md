# Skill catalog

All skills operate an authorized OXYGEN workspace. Install the kit from the README, then let your agent load the narrowest skill for the job. Supporting references and playbooks ship with each entrypoint.

| Skill | When to use it |
| --- | --- |
| [oxygen-onboarding](../skills/oxygen-onboarding/SKILL.md) | Guide OXYGEN onboarding: company context, first leads, a reviewed sequence, sender and bounded launch; set up daily Oxygent routines when requested. Use for 'get me started' or the first campaign and morning briefing. For a GTM diagnosis or plan, use oxygen-gtm-consultant. |
| [oxygen-gtm-consultant](../skills/oxygen-gtm-consultant/SKILL.md) | Be the user's GTM engineering consultant: assess the go-to-market from workspace data, find the binding constraint, agree the problem, design a custom motion and run it as a pilot with a success bar and a kill line. Use for 'pipeline is flat', 'outbound isn't working' or 'plan our GTM'. |
| [oxygen-gtm](../skills/oxygen-gtm/SKILL.md) | Route an OXYGEN GTM outcome to its native primitive and the feature skill that teaches it: Knowledge, Records, Tables, Messages, Posts, Signals, Dashboards, Ads, Tags, Sequences, Publishing, Workflows, Agents, Observability. Use as the fallback when no narrower skill matches. |
| [oxygen-tables](../skills/oxygen-tables/SKILL.md) | Build and run OXYGEN Tables: typed rows, choice fields, table links and lookups; AI, research, Classify, formula, tool, HTTP and template columns, reusable Functions, live feeds and webhooks, imports, follower orders, deduplication and folders. Covers pricing a column before it runs, one-row pilots, bounded batches and run reads. |
| [oxygen-enrichment](../skills/oxygen-enrichment/SKILL.md) | Enrich OXYGEN Table rows and single records: person and company profiles, funding, revenue, hiring and tech stack, work and personal email, mobile phone, LinkedIn URL and email or phone verification, through native waterfalls with free previews, one-row pilots and approved ceilings. |
| [oxygen-sourcing](../skills/oxygen-sourcing/SKILL.md) | Find companies and people that are not in the workspace yet and land them in OXYGEN Tables: account and TAM lists, lookalikes, hiring companies, local businesses, personas and contacts at named accounts, through free previews, typed plans, priced dry runs and approved live runs. |
| [oxygen-crm](../skills/oxygen-crm/SKILL.md) | Operate OXYGEN Records, the native CRM: objects, fields, identities and relationships, notes, tasks and files, imports from HubSpot, Attio and Pipedrive, list imports with do-not-contact first, bidirectional sync, and binding and promoting table rows onto records. |
| [oxygen-recipes](../skills/oxygen-recipes/SKILL.md) | Search, read and install OXYGEN plays: proven GTM motions with prerequisites, credit posture, approval gates and an optional kit of native stages. Use when the user names a play or wants a proven motion to borrow from; to design a motion for their company, use oxygen-gtm-consultant. |
| [oxygen-collaboration](../skills/oxygen-collaboration/SKILL.md) | Get a second party's documented go/no-go inside OXYGEN: threaded internal comments on any workspace object, approval requests assigned to named members, the opt-in gate that blocks a live launch until someone approves, and the restricted client role. Not for public comments on a published post, and not a substitute for a paid action's own approval. |
| [oxygen-quickstart](../skills/oxygen-quickstart/SKILL.md) | Run a safe first OXYGEN CLI session: verify identity and workspace, search capabilities and exact commands, create a small hosted Table, inspect it, and discover provider operations without executing paid calls or external writes. |
| [oxygen-workflow-authoring](../skills/oxygen-workflow-authoring/SKILL.md) | Build, run, or debug deterministic OXYGEN Workflows: schemas, triggers, branches, retries, approvals, durable runs, Blueprints, Teams notifications and MCP tools. Local files only author hosted definitions; adaptive goals use Agents and outreach cadence uses Sequences. |
| [oxygen-knowledge](../skills/oxygen-knowledge/SKILL.md) | Operate OXYGEN knowledge: index-first retrieval, wiki pages/folders, GitHub repository mounts, citations, revisions, sources, synthesis, proposals, and local mirror. Use for company/ICP context, positioning, offers, voice, prompts, rubrics, and learnings. |
| [oxygen-unibox](../skills/oxygen-unibox/SKILL.md) | Use OXYGEN Messages and the Unibox to find, read, classify, tag, archive, draft and reply in existing email, LinkedIn and WhatsApp conversations, send one direct email, start one WhatsApp chat or delete a sent LinkedIn message. Net-new LinkedIn outreach uses Sequences. |
| [oxygen-email-infra](../skills/oxygen-email-infra/SKILL.md) | Plan, set up and run OXYGEN cold email sending infrastructure: playbooks by market (Google/Microsoft mix, inbox count sized from the TAM), lookalike domains and DNS, managed and imported mailboxes, sender profiles and photos, OAuth, warm-up, recovery, egress and wind-down; also connect a customer's own inbox for Unibox history and CRM. |
| [oxygen-deliverability](../skills/oxygen-deliverability/SKILL.md) | Triage email deliverability, warmup and bounce evidence; compare workspace copies using Gmail Primary/categories and Microsoft Focused/Other; run approval-gated placement tests and manage monitoring. Results are directional; bounce auto-pause is authoritative. |
| [oxygen-sequencer](../skills/oxygen-sequencer/SKILL.md) | Run OXYGEN Sequences: net-new LinkedIn outreach, even one message, and multistep email, LinkedIn, WhatsApp, call and CRM-task cadences. Covers the launch ladder, send ceilings, enrollment, do-not-contact, reply-stop and recovery. Existing-thread replies and direct email use Messages. |
| [oxygen-publishing](../skills/oxygen-publishing/SKILL.md) | Use OXYGEN Posts and Publishing to draft, queue, approve, schedule and read back LinkedIn and X posts, answer public comments on owned posts, and read post analytics. Covers approval axes, the uncertain-publish lock, mentions, media, X threads and polls. |
| [oxygen-linkedin-content](../skills/oxygen-linkedin-content/SKILL.md) | Plan and write a week of LinkedIn posts from the workspace's Knowledge: pillars, funnel job, idea gate, hook, body, slop scrub, graphics rendered with OXYGEN visuals, review, hand-off to Publishing for approval, and learning from post analytics. Also a manual comment round. |
| [oxygen-signals](../skills/oxygen-signals/SKILL.md) | Capture and read OXYGEN Signals: your LinkedIn network, followers, viewers, invitations and post engagers; hiring, funding, tech and news signal searches; public profile watchers and keyword post search; competitor ads; standing auto-enroll into a Sequence. |
| [oxygen-table-tidy](../skills/oxygen-table-tidy/SKILL.md) | Tidy an OXYGEN Table: inspect duplicate columns, ordering, formatting, types, hide/archive candidates, and suspicious values; present findings by category; then apply only approved reversible fixes. This is table structure and cell formatting, not CRM record deduplication or merge. |
| [oxygen-diagnostics](../skills/oxygen-diagnostics/SKILL.md) | Diagnose a running OXYGEN workspace: trace a cell or record value and its provenance, explain stuck or failed runs, sweep and retry table failures, explain plan, credit and rate-limit refusals, and explain or reduce credit spend. Read-only investigation first. |
| [oxygen-feedback](../skills/oxygen-feedback/SKILL.md) | File feedback, praise, a feature request, or a reproducible OXYGEN bug report with the current transcript and environment context. Use only when the user explicitly wants to send feedback or agrees to file the report; diagnosing a run alone does not trigger submission. |
| [oxygen-clay-migration](../skills/oxygen-clay-migration/SKILL.md) | Move a Clay workspace into OXYGEN through browser sign-in: discover accessible resources, transfer data, rebuild native Tables, Records and Workflows, and verify coverage. Also handles a user-supplied Clay export. |
| [oxygen-ugc](../skills/oxygen-ugc/SKILL.md) | Operate UGC programs and independent creators: invitations, shared live knowledge, voice, topic-based drafts, approvals, sponsorship and bounded amplification. |
| [oxygen-custom-http](../skills/oxygen-custom-http/SKILL.md) | Register, connect, preview, run and remove reusable custom HTTP integrations: manifest schema, auth, path/query/body inputs, tool ids and Table tool columns. |
